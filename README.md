# home-like — лендинг

Статическая одностраничная визитка проекта **home-like** (домен: `homelike.be`).
Обычные HTML и CSS, без сборки, без JavaScript, без зависимостей.

## Состав репозитория

| Файл | Что внутри |
| --- | --- |
| `index.html` | вся страница: разметка, тексты и SVG-иллюстрация первого экрана |
| `assets/styles.css` | единственная таблица стилей; цвета, шрифты и размеры — в CSS-переменных вверху файла |
| `assets/favicon.svg` | фавиконка |
| `assets/og-image.svg` | исходник картинки для соцсетей |
| `assets/og-image.png` | та же картинка 1200×630, на неё ссылается `og:image` |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |
| `CNAME` | собственный домен для GitHub Pages (`homelike.be`) |

JavaScript на странице нет вообще: навигация, якоря и контактная ссылка работают без него.

## Как посмотреть локально

Достаточно любого простого HTTP-сервера (открывать `index.html` через `file://` тоже можно,
но сервер ближе к реальности):

```bash
cd путь/к/репозиторию
python3 -m http.server 8000
```

Затем открыть http://localhost:8000/.

## Что и где редактировать

**Тексты.** Все тексты лежат прямо в `index.html`, по порядку секций:
`header` → hero → `#problem` → `#approach` → `#status` → `#contact` → `footer`.
Заголовок вкладки и описание для поиска и соцсетей — в `<head>`
(`<title>`, `meta name="description"`, блок Open Graph).

**Цвета, шрифты, размеры.** Всё в начале `assets/styles.css`, в блоке `:root`:

```css
--bg: #faf5ee;      /* молочный фон */
--ink: #1e2a24;     /* тёмно-зелёный основной текст */
--accent: #b4552f;  /* терракотовый акцент */
--shell: 68rem;     /* максимальная ширина контента */
```

Цвета иллюстрации собраны там же — в секции `illustration palette`.
Шрифты системные (`--font-serif` для заголовков, `--font-sans` для текста),
внешние шрифты не загружаются.

**Контактный email.** Сейчас это `info@homelike.be`. Он встречается в `index.html` три раза:
кнопка «Write to us», ссылка-текст в блоке контактов и строка в подвале.
Тема письма зашита в ссылку: `?subject=Hello%20home-like`. Замена — обычным поиском по файлу.

**Иллюстрация.** Это инлайновый `<svg>` внутри `index.html` (секция hero), раскрашенный
классами из `styles.css`. Отдельная копия для соцсетей — в `assets/og-image.svg`;
после её изменения нужно перегенерировать PNG, например:
`rsvg-convert -w 1200 -h 630 assets/og-image.svg -o assets/og-image.png`.

## Публикация на GitHub Pages

1. Запушить содержимое в ветку `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
3. Branch: `main`, папка `/ (root)` → **Save**.
4. Через минуту-две сайт открывается по адресу `https://<аккаунт>.github.io/<репозиторий>/`.
   Все пути в HTML относительные, поэтому в подпапке сайт тоже работает.

### Свой домен

В репозитории уже лежит `CNAME` с `homelike.be` — GitHub Pages подхватывает его
и прописывает домен в настройках автоматически.

Проверить: **Settings → Pages → Custom domain** — там должен быть `homelike.be`,
рядом — статус проверки DNS. После успешной проверки стоит включить
**Enforce HTTPS** (галочка появляется не сразу, сертификат выпускается несколько минут).

Со стороны DNS для апекс-домена нужны A/AAAA-записи на адреса GitHub Pages
(и `CNAME`-запись `www` → `<аккаунт>.github.io`, если нужен `www`).

## Что проверить перед публикацией

- [ ] Письмо на `info@homelike.be` действительно доходит — отправить себе тестовое.
- [ ] Кнопки «Get in touch» и «Write to us» открывают почтовый клиент с темой «Hello home-like».
- [ ] В **Settings → Pages** выбран `main` / `/ (root)`, домен подтверждён, включён Enforce HTTPS.
- [ ] Сайт открывается и по `https://homelike.be/`, и по адресу `github.io` без смешанного контента.
- [ ] Тексты перечитаны: страница описывает идею проекта и не обещает услуг, которых пока нет.
- [ ] Превью ссылки в мессенджере/соцсети подтягивает `assets/og-image.png`.
