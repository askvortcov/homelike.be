# home-like — лендинг

Статическая визитка проекта **home-like** (домен: `homelike.be`) на трёх языках:
английский, французский и нидерландский. Обычные HTML и CSS, без сборки,
без JavaScript, без зависимостей.

## Состав репозитория

| Файл | Что внутри |
| --- | --- |
| `index.html` | английская версия (главная): разметка, тексты и SVG-иллюстрация |
| `fr/index.html` | французская версия |
| `nl/index.html` | нидерландская версия |
| `assets/styles.css` | единственная таблица стилей на все три страницы; цвета, шрифты и размеры — в CSS-переменных вверху файла |
| `assets/lang-redirect.js` | единственный скрипт на сайте: уводит с главной на `/fr/` или `/nl/`, если браузер предпочитает эти языки |
| `assets/favicon.svg` | фавиконка |
| `assets/og-image*.svg` | исходники картинок для соцсетей (общая + `-fr`, `-nl`) |
| `assets/og-image*.png` | те же картинки 1200×630, на них ссылается `og:image` |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |
| `CNAME` | собственный домен для GitHub Pages (`homelike.be`) |

JavaScript на сайте ровно один файл — автовыбор языка (см. ниже), и без него
тоже всё работает: навигация, якоря, переключение языков и контактная ссылка
не зависят от скриптов.

## Языки

Адреса: `/` (EN), `/fr/`, `/nl/`. Переключатель EN · FR · NL стоит в шапке каждой
страницы; текущий язык подсвечен и помечен `aria-current="page"`.

Три файла — это три независимые копии одной и той же разметки: общий только CSS.
Так задумано — никакой сборки и шаблонизатора, каждый файл можно править руками.
Если меняется структура блоков, изменение нужно повторить во всех трёх файлах;
если меняется только текст — достаточно одного.

Что в каждой версии своё:

- `<html lang="...">`, `<title>`, `meta description` и блок Open Graph
  (`og:locale`, своя `og:image`: `og-image.png` / `-fr` / `-nl`);
- `link rel="canonical"` на свой адрес; набор `link rel="alternate" hreflang="..."`
  одинаковый на всех страницах и перечисляет все три версии плюс `x-default` → EN;
- тема письма в `mailto`: `Hello home-like` / `Bonjour home-like` / `Hallo home-like`;
- относительные пути к ресурсам: `assets/...` в корне и `../assets/...` в `fr/` и `nl/`.

Чтобы добавить четвёртый язык: скопировать `fr/` в новую папку (например, `de/`),
перевести тексты, поменять `lang`, `canonical`, `og:*`, добавить ссылку в
переключатель и `hreflang` во **всех** страницах, а также добавить код языка
в `assets/lang-redirect.js`.

### Автовыбор языка

GitHub Pages не умеет согласовывать язык на стороне сервера, поэтому это делает
`assets/lang-redirect.js` — он подключён только на главной и читает список языков
браузера (`navigator.languages`, тот же порядок, что и в заголовке `Accept-Language`).

Правила намеренно осторожные:

- если браузер не сообщает предпочтений — не происходит ничего, остаётся английская версия;
- языки перебираются по приоритету: первым совпал `en` — остаёмся, `fr` или `nl` — уходим
  на `/fr/` или `/nl/`; незнакомые языки пропускаются (с `de, fr, en` человек попадёт на французскую);
- явный выбор сильнее: ссылка EN в переключателе ведёт на `../?lang=en`, и переход
  с любой нашей же страницы редирект не запускает — вернуться на английскую всегда можно;
- используется `location.replace`, поэтому кнопка «назад» ведёт туда, откуда человек пришёл,
  а не зацикливается;
- запрос и якорь сохраняются: `/?utm=x#contact` → `/fr/?utm=x#contact`.

Скрипт работает только на главной: `/fr/` и `/nl/` никуда не перенаправляют.
Чтобы отключить автовыбор совсем, достаточно удалить строку `<script src="assets/lang-redirect.js">`
из `index.html` — остальное продолжит работать.

Поисковикам это не мешает: у каждой версии свой `canonical`, все три перечислены
в `hreflang`, а `x-default` указывает на английскую.

## Как посмотреть локально

Достаточно любого простого HTTP-сервера (открывать `index.html` через `file://` тоже можно,
но сервер ближе к реальности):

```bash
cd путь/к/репозиторию
python3 -m http.server 8000
```

Затем открыть http://localhost:8000/.

## Что и где редактировать

**Тексты.** Все тексты лежат прямо в HTML-файлах (`index.html`, `fr/index.html`,
`nl/index.html`), по порядку секций:
`header` → hero → `#problem` → `#approach` → `#status` → `#contact` → `footer`.
Заголовок вкладки и описание для поиска и соцсетей — в `<head>`
(`<title>`, `meta name="description"`, блок Open Graph).
Идентификаторы секций (`#problem`, `#approach`, `#status`, `#contact`) во всех
версиях одинаковые — переведены только подписи ссылок.

**Цвета, шрифты, размеры.** Всё в начале `assets/styles.css`, в блоке `:root`:

```css
--bg: #faf5ee;      /* молочный фон */
--ink: #1e2a24;     /* тёмно-зелёный основной текст */
--accent: #b4552f;  /* терракотовый акцент */
--shell: 68rem;     /* максимальная ширина контента */
```

Цвета иллюстрации собраны там же — в секции `illustration palette`.
Шрифты системные (`--font-serif` для заголовков, `--font-sans` для текста),
внешние шрифты не загружаются.

**Контактный email.** Сейчас это `info@homelike.be`. В каждой из трёх страниц он
встречается три раза: кнопка в блоке контактов, ссылка-текст рядом с ней и строка
в подвале. Тема письма зашита в ссылку (`?subject=Hello%20home-like` и переводы).
Замена — поиском по всем файлам, например:
`grep -rl info@homelike.be . | xargs sed -i '' 's/info@homelike.be/новый@адрес/g'`

**Иллюстрация.** Это инлайновый `<svg>` внутри каждой страницы (секция hero),
раскрашенный классами из `styles.css`; переведены в нём только `<title>` и `<desc>`
для скринридеров. Отдельные копии для соцсетей — `assets/og-image.svg`,
`og-image-fr.svg`, `og-image-nl.svg`; после изменения нужно перегенерировать PNG:
`rsvg-convert -w 1200 -h 630 assets/og-image-fr.svg -o assets/og-image-fr.png`.

## Публикация на GitHub Pages

1. Запушить содержимое в ветку `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
3. Branch: `main`, папка `/ (root)` → **Save**.
4. Через минуту-две сайт открывается по адресу `https://<аккаунт>.github.io/<репозиторий>/`.
   Все пути в HTML относительные, поэтому в подпапке сайт тоже работает.

### Свой домен

В репозитории уже лежит `CNAME` с `homelike.be` — GitHub Pages подхватывает его
и прописывает домен в настройках автоматически.

Проверить: **Settings → Pages → Custom domain** — там должен быть `homelike.be`,
рядом — статус проверки DNS. После успешной проверки стоит включить
**Enforce HTTPS** (галочка появляется не сразу, сертификат выпускается несколько минут).

Со стороны DNS для апекс-домена нужны A/AAAA-записи на адреса GitHub Pages
(и `CNAME`-запись `www` → `<аккаунт>.github.io`, если нужен `www`).

## Что проверить перед публикацией

- [ ] Письмо на `info@homelike.be` действительно доходит — отправить себе тестовое.
- [ ] Кнопки «Get in touch» и «Write to us» открывают почтовый клиент с темой «Hello home-like».
- [ ] В **Settings → Pages** выбран `main` / `/ (root)`, домен подтверждён, включён Enforce HTTPS.
- [ ] Сайт открывается и по `https://homelike.be/`, и по адресу `github.io` без смешанного контента.
- [ ] Тексты перечитаны: страница описывает идею проекта и не обещает услуг, которых пока нет.
- [ ] Превью ссылки в мессенджере/соцсети подтягивает `assets/og-image*.png`.
- [ ] Открываются все три версии: `/`, `/fr/`, `/nl/`, и переключатель языков водит между ними.
- [ ] Автовыбор языка: в браузере с французским или нидерландским главная уводит
      на свою версию, а ссылка EN возвращает на английскую и там оставляет.
- [ ] Французский и нидерландский тексты вычитаны носителем языка — они написаны
      без участия переводчика-человека.
